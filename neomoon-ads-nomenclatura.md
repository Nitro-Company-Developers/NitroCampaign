# Guia de Nomenclatura dos Vídeos e Imagens

## Visão geral

Este guia define os campos usados para nomear vídeos e imagens de anúncios, com opções, descrições e formatos esperados.

## Tabela de campos

### Campo: Sequência
- **Tipo de campo:** Selecionável.
- **Itens:** Numeral crescente.
- **Descrição:** Ordem sequencial do material (ex: 01, 02, 03).  
- **Formato:** Definido pelo time de Tech para facilitar a busca.

### Campo: Copy
- **Tipo de campo:** Selecionável.
- **Itens:**
  - Henrique
  - Varsi
  - Achraf
  - Matheus
  - Outro
- **Descrição:** Identifica o responsável/autor da copy do anúncio.
- **Formato:** Seleção de um dos nomes disponíveis ou "Outro".

### Campo: Rede de Tráfego
- **Tipo de campo:** Selecionável.
- **Itens:**
  - Meta
  - Youtube
  - Google
  - Taboola
- **Descrição:** Plataforma onde o anúncio será veiculado.
- **Formato:** Seleção de uma das redes listadas.

### Campo: Oferta
- **Tipo de campo:** Escrito.
- **Itens:** Livre (com código sugerido entre colchetes, ex: [AA00]).
- **Descrição:**
  - Identifica a oferta/campanha, com codificação padrão.
  - Exemplo:  
    - Darkspot, primeiro teste = DS01.  
    - Wrinkles = WR01.
  - Se a campanha de Darkspot parar e depois voltar, volta como DS01 ou recebe um novo código caso o funil seja totalmente novo (ex: VSL nova).
- **Formato:** Código alfanumérico curto (ex: DS01, WR01).

### Campo: AD
- **Tipo de campo:** Escrito.
- **Itens:** Numeral crescente ou nomenclatura de ad de outra rede
- **Descrição:** Código do anúncio, aceita letras e números.
- **Formato:** Exemplos: AD1, AD11, ADFB76.

### Campo: Hook
- **Tipo de campo:** Escrito.
- **Itens:** Numeral crescente (H01, H02…) ou referência (TD, HI…).
- **Descrição (vídeo):**
  - Representa os primeiros 3 a 10 segundos do vídeo.
  - Pode ser sequencial (H01, H02…) se variar apenas a abertura.
  - Pode levar um nome/referência, ex: TD (Tela dividida).
- **Descrição (imagem):** Hook é o H1. Refere-se ao cabeçalho/título da peça.
- **Formato:** Código curto (ex: H01, TD, HI).

### Campo: Avatar
- **Tipo de campo:** Selecionável.
- **Itens:** Numeral crescente (A01, A02…) ou N/A.
- **Descrição:** Avatar/pessoa/persona principal do anúncio (ex: variações com asiática, branca, negra etc.).
- **Observação:** Usar N/A para anúncios apenas com imagem (sem avatar específico).
- **Formato:** A01, A02, A03, ou N/A.

### Campo: Tipo de Campanha
- **Tipo de campo:** Selecionável.
- **Itens:**
  - Venda
  - Captação de Lead
  - Alcance
  - Engajamento
- **Descrição:** Objetivo principal da campanha.
- **Formato:** Seleção de uma das opções.

### Campo: Tipo de Avatar
- **Tipo de campo:** Selecionável.
- **Itens:**
  - IA
  - Ator
  - Influencer
  - Micro Celeb
  - Celebridade
  - N/A
- **Descrição:** Classificação do tipo de avatar utilizado no anúncio.
- **Observação:** N/A para anúncios apenas com imagem (sem avatar).

### Campo: Tipo de Arquivo
- **Tipo de campo:** Selecionável.
- **Itens:**
  - Imagem
  - Vídeo
- **Descrição:** Define o tipo do arquivo criativo.
- **Formato:** Seleção entre "Imagem" ou "Vídeo".

### Campo: Formato
- **Tipo de campo:** Escrito.
- **Itens:** Aberto, mas com referências padronizadas.
- **Descrição:**
  - Pode usar padrões como: UGC, REELS, ANIMAÇÃO, REPORTAGEM, COMPARAÇÃO, AXD.
  - Campo aberto para cadastro inicial de novos formatos/padrões.
- **Formato:** String curta, com o nome do formato.

### Campo: Editor
- **Tipo de campo:** Selecionável.
- **Itens:**
  - Cris
  - Boturi
  - Jeff
  - Filipe
  - N/A
- **Descrição:** Nome do editor responsável pelo criativo.
- **Observação:** N/A para anúncios que são apenas imagem (sem edição de vídeo).
